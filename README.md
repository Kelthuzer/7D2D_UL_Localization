# Undead Legacy — Russian Localization

Русская локализация для **Undead Legacy Experimental** в **7 Days to Die**.

Релизы перевода привязаны к версии самой Undead Legacy. Например, релиз с тегом `v2.7.23` предназначен для **Undead Legacy v2.7.23**.

## Быстрая установка / обновление

Для Windows доступен автоматический установщик:

**`Install_Russian_Translation.bat`**

Скачать последнюю версию установщика можно по постоянной ссылке:

```text
https://github.com/Kelthuzer/7D2D_UL_Localization/releases/latest/download/Install_Russian_Translation.bat
```

Запустите BAT обычным двойным щелчком. Он:

- пытается автоматически найти установленную `7 Days To Die` с Undead Legacy;
- при необходимости позволяет указать папку игры вручную;
- скачивает последнюю русскую локализацию;
- сохраняет предыдущий `Russian.txt` как `Russian.txt.bak`;
- устанавливает новый перевод в нужную папку.

Установщик рассчитан на **Windows 7, 8, 8.1, 10 и 11**.

После первого скачивания BAT можно сохранить у себя и использовать его для последующих обновлений перевода.

## Ручная установка

В каждом GitHub Release находится один архив:

**`UndeadLegacy_Russian.zip`**

Постоянная ссылка на последнюю версию:

```text
https://github.com/Kelthuzer/7D2D_UL_Localization/releases/latest/download/UndeadLegacy_Russian.zip
```

Распакуйте архив непосредственно в корневую папку `7 Days To Die` с заменой файла.

После установки перевод должен находиться здесь:

```text
7 Days To Die\Mods\UndeadLegacy\Config\Localization\Russian.txt
```

Архив уже содержит структуру каталогов `Mods\UndeadLegacy\Config\Localization`, поэтому вручную переносить `Russian.txt` по папкам не требуется.

## Релизы

Название релиза соответствует версии Undead Legacy:

```text
Undead Legacy v2.7.23 — Russian Localization
```

Тег такого релиза:

```text
v2.7.23
```

При выходе новой Experimental-версии Undead Legacy создаётся новый релиз перевода с соответствующим тегом.
